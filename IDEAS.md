## Claude usage tracker (side project, not Glass Clock)
*Added 2026-10-21. Status: idea only, not now.*

- A simple tracker showing how much of your Claude usage you've used and what's left, so you can plan sessions.
- Help you use less and get more done with what you use. For example:
  - batch small requests together
  - compact long chats sooner
  - use a cheaper model for simple jobs
  - run big work overnight
- Possibly a tool that suggests these automatically.
