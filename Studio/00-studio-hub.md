# Studio hub

How everything connects. Glass Clock is app #1, and the way you build it becomes the template for the rest.

```
Alpha Design Media (the umbrella: branding, accounts, legal name)
 ├─ Apps: small iPad utilities
 │    ├─ Glass Clock   ← live first (this repo)
 │    └─ App #2, #3…   ← copy `new-app-template.md`
 ├─ Strange Store: physical + digital products
 └─ Learning: how to use AI for big ideas with ADHD
```

## What's shared across all of it
- **One Apple Developer account.** Every app uses it.
- **One support/contact email** and one website section per app (portfolio site).
- **One look.** Icon style, screenshot style and tone of voice carry from app to app, so a bundle feels like a family.
- **One set of templates** in this folder: listing copy, privacy policy, checklist.

## Rule of thumb
Glass Clock gets finished first. Everything else waits in `ideas-parking-lot.md`.
