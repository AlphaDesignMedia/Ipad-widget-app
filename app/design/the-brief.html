3Should you get a VPS (a rented server)?

The key fact: iPad apps can only be built on a Mac. A normal VPS runs Linux, so it can't build or install your app. Your Mac is already your server.

My pick: no VPS yet. Keep the Mac on, and run Remote Control in the project folder so Rob shows up in your Claude Code app wherever you are. A VPS earns its place when the dashboard needs live two-way data, and that's step 2's "later".

Run this in a terminal in the project folder on the Mac. That session then appears in the Claude Code app on your iPad, and you can type to it from anywhere. Keep the Mac awake: System Settings → Energy → "Prevent automatic sleeping".

5Speed and stability rules

  • A one-second hiccup is fine. Freezes and crashes are not.
  • Nothing redraws when nothing's changed: no idle timers, no full-screen layers.
  • Broken plugin → park it → 🎟 ticket → Jules fixes it → you say "bring it back".
  • Put numbers on it: the frame meter (--meter) and saved crash reports.
  • Tess tests in the simulator before anything reaches the iPad.
