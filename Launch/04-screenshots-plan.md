# Screenshots plan

**Required size:** 13-inch iPad display. Portrait 2064 x 2752 or landscape 2752 x 2064 (2048 x 2732 also accepted). Apple scales this set down for smaller iPads. Up to 10 screenshots, 3 to 5 is plenty.

**Easy way:** run on your 12.9-inch iPad Pro (or the iPad Pro 13-inch simulator) and take screenshots with Top button + Volume up. Your `References/simulator/` folder already holds working shots to base these on.

## The set (in order)
1. **Home Screen with the widget**, nicely styled, on a good wallpaper (the hero shot)
2. **The customiser**, live preview large, controls below
3. **Presets**, three different looks side by side
4. **All four widget sizes** on one Home Screen
5. **Dark / Clear / Tinted** comparison

## Tips
- Use a calm, attractive wallpaper. It does most of the selling.
- Optional: add a one-line caption above each shot (Affinity or Figma). Keep them short: "Style it live", "Every widget size".
- No device frames needed.
